Winning Post 10 2026 (PC) - English Patch v0.4 (BETA)
=====================================================

Translates menus, dialogue, help, the glossary, race commentary subtitles,
cutscene subtitles, Legends (sorted A-Z), DLC descriptions, year screens and more.

You need your own copy of Winning Post 10 2026 (PC). DLC is NOT required.

GAME VERSION: works on BOTH game versions, 1.0.4 (the current Steam version) and 1.0.1.1.
You don't need to check your version: the installer detects it and installs the right
files automatically. It shows "Game version: ..." when it starts.
Other versions are not supported - the installer will say so and change nothing.

UPDATING FROM v0.2 / v0.3 / v0.3.1: just run INSTALL.bat from this folder - it updates the patch.
UPDATING FROM v0.1: run UNINSTALL.bat from your OLD v0.1 folder first, then INSTALL.bat here.
If Steam updated your game from 1.0.1.1 to 1.0.4, that's fine too - run INSTALL.bat again.
Your saves are not affected.

HOW TO INSTALL (2 steps)
------------------------
1. Right-click the zip file > "Extract All..." (do NOT run it from inside the zip).
2. Close the game, open the extracted folder and double-click INSTALL.bat.

That's it. The installer finds your game automatically (Steam or any other folder).
If it can't, a window opens so you can pick the game folder (the one with WP10_2026.exe).
When it says "English patch installed!", start the game from Steam as normal.

Your original files are saved in a "WP10_EN_backup" folder inside the game folder.


HOW TO UNINSTALL
----------------
Close the game and double-click UNINSTALL.bat. The game goes back to Japanese.


FULLSCREEN (optional)
---------------------
Double-click Fullscreen_ON.reg to start the game in fullscreen
(Fullscreen_OFF.reg = windowed). Click "Yes" when Windows asks.


HORSE NAMES (English names up to 18 characters)
-----------------------------------------------
You can name and rename horses in English, up to 18 characters including spaces,
the same limit used for real racehorse names in Australia, the UK and worldwide.
(The Japanese game allowed 9 katakana, which take the same space as 18 letters.)

- Letters, numbers, spaces, apostrophes ('), full stops (.) and hyphens (-) are allowed.
- The name box only shows 12 boxes. This is a limit of the game's screen, not of the
  name: keep typing past the 12th box and the full name (up to 18) is still saved.
  Typing stops automatically at 18.
- Full names show in dialogue, on the horse's info screen and elsewhere. On a few very
  crowded screens (some lists) a long name may be shortened.
- Long names are stored in the file WP10_EN_longnames.bin in the game folder.
  Don't delete it, or long names will be cut to 9 letters in dialogue.


FAQ / PROBLEMS
--------------
Q: "The patch files are missing" / "Extract the zip first"
A: You ran INSTALL.bat from inside the zip. Right-click the zip > Extract All...,
   then run INSTALL.bat from the extracted folder.

Q: A blue "Windows protected your PC" box appeared.
A: Click "More info" > "Run anyway". The installer only copies files into the game folder.

Q: It says the game is still running.
A: Close Winning Post 10 completely (check the taskbar), then press Enter.

Q: It asks me for the game folder.
A: Pick the folder that contains WP10_2026.exe. On Steam you can find it with
   right-click Winning Post 10 2026 > Manage > Browse local files.

Q: It says my files "don't match the version this patch was made for".
A: Nothing was changed. Usually:
   - An older version of this patch is installed: run the OLD UNINSTALL.bat first.
   - Another mod changed the files: in Steam, right-click the game > Properties >
     Installed Files > "Verify integrity of game files", then run INSTALL.bat again.
   - Your game is a version other than 1.0.4 or 1.0.1.1 (for example a newer
     Steam update): wait for an updated patch.

Q: The game is Japanese again.
A: A Steam update or "Verify integrity" restores the Japanese files.
   Just run INSTALL.bat again.

Q: Some text is still Japanese / cut off / looks odd.
A: This is a beta. Please report it with a screenshot and say where in the game you were.
